Compilation Process
=================================================

Step 1: Input file is given through the command line. The compiler reads the file in one go.
Step 2: The lexer tokenizes the source file.
Step 3: The parser parses the tokens and creates an Abstract Syntax Tree (ast).
Step 4: The ast is passed to the semantic analyzer (sem analyzer).

  * Semantic Analysis Process
Step 5: Sem analyzer goes through the top level declaration declared in lexical order and
    predeclares each one of them.
Step 6: Analyzes the declaration according to its type.
    If the decl is variable decl, it declares a global variable.
    If the decl is constant decl, it declares a global constant.
    If the decl is struct decl, it declares a struct.
    If the decl is union decl, it declares a union. (Not implemented yet)

Data types
=================================================
Boolean type : bool
- The boolean type can take on only two values: true and false
- Size: 1, Alignment: 1
- Range: 0x00 to 0xFF
- The value 0x00 is designated as false and any value other than 0x00 is designated as true

Char type : char
- char type can hold a value of a Unicode scalar value (i.e. codepoint that is not a surrogate)
    represented by a 32-bit unsigned word.
- Size: 1, Alignment: 1
- Range: 0x0000 to 0xD7FF or 0xE000 to 0x10FFFF
- char is effectively a UTF-32 string of length 1.

Noreturn type : noreturn
- noreturn is type with no values and represents the value of computations that never return
- noreturn type can be coerced (or be casted) into any type

Predefined operators
=================================================
int: i8, i16, i32, i64, isize
     u8, u16, u32, u64, usize
signed_int: i8, i16, i32, i64, isize
unsigned_int: u8, u16, u32, u64, usize
float: f32, f64

1. postfix operator 'a = b[c]'
    b can be of type:
        1)  [_] T               -- Array type
        2)  [] T                -- Fat pointer type
    c can be of type:
        1)  int                 -- Array type
        2)  int                 -- Fat pointer type
    a will be of type:
        1)  [_] T -> T          -- Array type
        2)  [] T  -> T          -- Fat pointer type

2. unary operator 'a = *b'
    b can be of type:
        *T                  -- Pointer
    a will be of type:
        *T -> T             -- Pointer

3. unary operator 'a = -b'
    b can be of type:
        int                 -- Integer
        float               -- Float
    a will be of type:
        int -> int          -- Integer
        float -> float      -- Float

3. unary operator 'a = ~b'
    b can be of type:
        int                 -- Integer
    a will be of type:
        int -> int          -- Integer
